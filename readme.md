## Requirements

- Java Development Kit (JDK) 17 or newer
- A POSIX-compatible shell for the commands below
- Maven 3.x only when running the Part 1 JUnit suite

Both applications use only the Java standard library at runtime. JUnit is scoped to Part 1's automated tests through Maven.

## Quick start

### Part 1: Student Job Portal

```sh
cd "1. Part 1"
find src/main/java -name '*.java' -print0 | xargs -0 javac --release 17 -d bin
java -cp bin com.studentjobportal.StudentJobPortal
```

Run the automated tests with:

```sh
cd "1. Part 1"
mvn test
```

### Part 2: Module Catalogue benchmark

```sh
cd "2. Part 2"
find src -name '*.java' -print0 | xargs -0 javac --release 17 -d out
java -cp out run_benchmarks
```

The Part 2 command loads each supplied one-million-record CSV and reports loading time, binary-catalogue build/sort time, average search time, and measured search speed-up. Results vary by JVM and machine; the README for that part explains how to interpret the cases.
